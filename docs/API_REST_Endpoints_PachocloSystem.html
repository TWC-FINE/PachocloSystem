MicroservicioMétodoEndpointDescripción

PacientesPUT/api/pacientes/{id}Actualizar paciente
PacientesPATCH/api/pacientes/{id}/habitacionCambiar solo la habitación del paciente
PacientesDELETE/api/pacientes/{id}Dar de baja al paciente (baja lógica: se conserva con su historial)
